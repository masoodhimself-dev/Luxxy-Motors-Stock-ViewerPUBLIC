Build a mobile-first used-car stock website for a UK dealer called Luxxy Motors (Harrow).

The user will upload a JSON file of current stock. The site must parse it and show every vehicle with photos. Do not hardcode cars. Do not fetch AutoTrader. Local JSON only, kept in memory / localStorage after upload.

JSON SHAPE (handle all of these):

{ "dealerName", "count", "scrapedAt", "cars": [ ... ] } ← this is the real file
A bare array of car objects
A car may have plate or only registration (e.g. "2024 (24 reg)")
Each car looks like:

IMAGES (critical):

Photos are public HTTPS URLs on m.atcdn.co.uk. Use them directly as <img src>. Do not download, proxy, or convert to base64.
Set referrerPolicy="no-referrer" and loading="lazy" on imgs. On error, show a grey placeholder, do not break the card.
For the stock-grid thumbnail, do NOT blindly use heroImage (it is often an interior). Prefer the first images[] entry whose caption matches /front|side|exterior/i. Fall back to heroImage, then images[0].url.
Vehicle detail page: full gallery. Click a thumb to make it the large shot. Show caption if present. Keyboard + swipe on mobile.
images may be {url, caption} objects OR plain URL strings. Support both.
UPLOAD:

Prominent “Upload stock JSON” dropzone on first visit (also in the header after data is loaded).
Accept .json. Parse, validate that cars (or the root array) has items, then render.
Persist last upload in localStorage so refresh keeps the stock.
Show dealer name, vehicle count, and scrapedAt if present.
Clear error if the file is not this shape.
PAGES:

Stock grid (home). Card: photo, title, variant, price, mileage, year, plate, Cat S / Cat N pill when writeOffCategory is "S" or "N". Click card → detail.
Vehicle detail: big gallery, specs (year, mileage, fuel, gearbox, body, colour, engine, doors, seats, owners, Euro class, drivetrain), Cat badge, plate, price. Button “View on AutoTrader” if advertUrl exists (new tab).
Filters/sort on the grid: search box (make/model/plate/title), make, min/max price, Cat S / Cat N / no write-off, sort price and mileage.
UI:

UK dealer look. Dark header, white cards, GBP with Intl.NumberFormat('en-GB', { style: 'currency', currency: 'GBP', maximumFractionDigits: 0 }). Mileage like 22,000 miles.
Responsive: 1 col mobile, 2 tablet, 3 desktop.
Stack: Vite + React + TypeScript. No backend. Works on Replit preview.
Empty state explains: upload full-stock.json.
Do not invent extra vehicles. Do not put fake phone numbers in. Just the stock viewer.
