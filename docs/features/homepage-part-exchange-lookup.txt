Homepage part exchange and make-logo placements — 1 November 2026

read-only MOT mileage endpoint before opening the part-exchange page. Both
homepage entry points use an explicit Find my car button. There are no lookups
while typing. The active request has a 12-second deadline; stale registration,
concurrent-entry, unmount, timeout and retry cases cannot apply or navigate with
an old result. A failed lookup offers ordinary manual entry.

in memory for up to five minutes, bound to the page origin and canonical dealer.

parameters. The destination consumes the handoff, retains a seed only for its

contact answers and customer-owned model/mileage corrections remain intact,
including when session storage cannot be written.

odometer check, without the calculation explanation. The editable valuation
message identifies the customer's car and selected current stock car. Sending
still needs the existing explicit review, contact validation and Send/WhatsApp
action. Browser checks did not submit anything; the temporary tab draft was
cleared afterwards.
