# Enquiry checks, AI folder and Archive

AI drafts use one shared context builder for manual Inbox replies and automatic Cazoo drafts. A relevant MOT/history/expiry question calls the existing cache-aware, quota-controlled MOT service using only the server-selected stock registration. Customer text cannot select a destination or cause arbitrary API calls. Failed lookups remain explicit; advertised dates are not presented as verified MOT results. Equipment, registration and dealer policies use the supplied published stock/settings. Evidence and policy excerpts are bounded. Luna remains the drafting model; no automatic sending or booking adapter is enabled.

The private `ai_assistance_requests.context_audit` stores the selected published vehicle facts, redacted question checks, sources, outcomes, timestamps and model. The staff-only `/api/staff/enquiries/:id/ai-checks` endpoint returns the latest successful audit for that same dealership/enquiry. Older drafts have no invented audit. Both fresh and replayed staff results are checked under the enquiry lock. Archiving, editing or merging while a request runs prevents stale completion. The Cazoo draft insert also rechecks the enquiry under lock.

Inbox has Enquiries, AI enquiries and Archive folders. AI classification requires recorded provider automation state; a Cazoo stock label or a manually requested AI draft alone does not qualify. Explicit combined cases remain together. Cazoo automation additionally requires the existing owner-managed provider opt-in, verified stock, dedicated receiving mailbox and enabled AI. Auto Trader remains unavailable until a partner adapter exists.

Archive and restore are staff writes requiring `sales.manage`, an allowed origin and the expected workspace revision. Active scheduled/arrived test drives and merged cases cannot be archived. Queued/in-flight mail blocks archive. Saved drafts remain, automatic work pauses, and the UI blocks archiving unsaved text. A verified incoming customer reply restores the archived enquiry. Sending and automated AI completion recheck archive state under the same enquiry locks.

Archive is recoverable for 30 days from the archive time. The hourly retention worker then reuses the existing permanent-deletion assessment and locks. Financial, reservation, document and active-booking protections remain. Protected cases retain a reason and are reconsidered daily so they do not starve other due records. Deletion removes the Inbox case and its owned conversation records, clears its private AI context/result while preserving usage totals, and retains protected sales/payment/customer/lead records. This is not an account-wide personal-data erasure mechanism.

Regression coverage includes optional-contact resilience, sender/tenant isolation, MOT success/failure/history bounds, archived generation races, archive/restore/revision conflicts, protected retention, incoming-reply lock order, outbox suppression, unsaved text protection, and phone/tablet/desktop folder flows using fictional intercepted browser fixtures.
