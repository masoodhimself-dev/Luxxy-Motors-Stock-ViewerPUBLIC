# Registration plate groundwork

Shared component: `src/components/uk-number-plate.tsx`; presentation only.
Formatter: `src/lib/registration-display.ts`. Database values, import parsing,
registration validation and invoice/payment records are unchanged.

- White front / yellow rear; small, medium and large sizes.
- Real accessible, selectable text; no rasterised lettering.
- Current `MM00 MMM`, prefix `M222 MMM`, suffix `MMM 222M`, dateless/NI
  `MMM 3333` / `MMM 222` and reversed dateless groupings are retained.
- Display spacing is separate from editable form values, so typing does not
  insert spaces or move the caret. Existing part-exchange input constraints stay.
- Missing/age-only values display `Registration not added`, never a fabricated
  plate. Existing car/year labels can still be shown outside this component.
- Existing public part-exchange, booking and comparison consumers use the shared
  component. Customer vehicle identity and staff inventory rows now use it too.
- Bulk entry retains its existing input, focus/ref and optimistic-locking save
  workflow; its font can be set with the same variable as the display component.

## Approved production assets

Installed from `dealership-registration-plate-production.zip`; all manifest hashes
verified. The supplied WOFF matches the approved review byte-for-byte. Production
TSX, CSS, flag geometry and both WOFF/TTF files are retained under
`components/registration-plate/`, with code and font notices. No review scripts run.
The font licence is also published at `/licences/registration-plate-font.txt`.

The existing `UKNumberPlate` API wraps the supplied display component and passes
`formatRegistrationPlate` as its formatter. Editable forms retain their input
value, callbacks, constraints, refs and request workflow. The approved identifier
is on by default; space-limited cards/comparison views can use `showFlag={false}`.

The only font change is registration lettering. Bulk entry shares the same
self-hosted face and approved Union Flag. Sales form inputs preserve completed
sale disabling and optional registration behaviour. Stored/issued invoice PDF
archives are not regenerated by a visual web-component update; their existing
renderer remains separate from HTML/CSS printing.

Checks cover frontend tests, typecheck/build and responsive browser layouts.
These are screen components, not artwork certified for physical plate manufacture.
