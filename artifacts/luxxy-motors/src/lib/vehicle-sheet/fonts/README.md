# Public Multi-Choice vehicle-sheet fonts

`../multi-choice-fonts.ts` embeds the exact existing, locally hosted Montserrat
Latin WOFF2 subsets listed below. They were derived from the user-supplied
Montserrat files in `heston-assets/fonts/`; the website already distributes
these same subsets. No external font service or runtime download is required.

- `public/brand/multi-choice-motors/fonts/montserrat-latin-400.woff2` — 19,304 bytes; SHA-256 `e038c35eb08bb80d583cc52a18fe1fd259fc1fc405bd67119728c9d5b6fb67df`.
- `public/brand/multi-choice-motors/fonts/montserrat-latin-700.woff2` — 19,748 bytes; SHA-256 `a8aabe8de666d2b664a0cf80710c097a252e933c908373fb0601627d88ce355f`.

The print-only CSS alias is `LuxxySheetSans`. It preserves the existing
font-loading checks and is installed only for a validated public vehicle URL
on `multichoicemotors.co.uk` or `www.multichoicemotors.co.uk`. Other dealers
retain the existing embedded DejaVu Sans faces. Registration plates retain
their separate Forecourt Plate UK face. This module is not used by invoices.
