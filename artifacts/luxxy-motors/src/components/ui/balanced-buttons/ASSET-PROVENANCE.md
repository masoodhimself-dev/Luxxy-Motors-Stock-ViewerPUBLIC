# Assets and commercial use

The button source/CSS and documentation were created for this dealership brief. They may be used, modified and integrated into commercial dealership websites, staff portals and administration platforms. No additional package fee or attribution requirement is imposed by this delivery; this does not amend applicable OpenAI terms or third-party conditions.

All 21 supplied SVG files were copied unchanged from the existing `dealership-extension-approval.zip`: 20 `*-standard.svg` custom concepts plus the official WhatsApp artwork. Their individual SHA-256 hashes are in `assets/manifest.json`. There are no newly drawn icons, old outline-pack substitutions, emoji, stock icon libraries, fonts, raster images or equipment illustrations in this package. CSS spinner geometry is a functional loading indicator, not an added icon asset.

The upstream pack identifies eight previously approved silhouettes and twelve extension samples. This button delivery reuses the supplied files; it does not complete or alter the wider icon-family project. The original source rights and provenance notes are preserved in `assets/UPSTREAM-*`.

WhatsApp is Meta/WhatsApp brand material, not covered by the custom-asset grant. Its supplied file is unchanged, with SHA-256 `68a1b3b3ab8fbfe087f72560c8a811165f53a1ebdacf46c723c765923d38f842`. The upstream provenance records the official glyph and prior normalisation; no further geometry or paint changes were made. Existing brand usage conditions still apply.

React and React DOM are bundled only into the offline review under their MIT licence. Production imports them as peers. Their notices are in `THIRD-PARTY-NOTICES.txt`. The review uses the original system font stack with local fallback; no font files are embedded or fetched. Existing gold/ink values, demonstration names, vehicles and amounts are confined to the review. No live records are present.
